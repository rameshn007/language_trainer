# Vocabulary, Comparatives & Time Markers (assets/ano_words_phrases.md)

## Core Vocabulary & Phrases (Corrected & Standardized)

| Portugues | English |
| :---- | :---- |
| há | for (time duration) / ago |
| desde | since / from (starting point) |
| final de tarde | late afternoon / early evening |
| Casa da Música | Casa da Música (Porto concert hall) |
| A Maria faz visitas guiadas desde que trabalha na Casa da Música | Maria has been giving guided tours since she started working at Casa da Música |
| Os amigos estão na esplanada há meia hora | The friends have been on the terrace for half an hour |
| A Olívia faz campismo desde criança | Olívia has been camping since childhood |
| A atleta olímpica pratica natação há mais de dez anos | The Olympic athlete has been practicing swimming for more than ten years |
| o nosso casamento | our wedding / our marriage |
| casar-se | to get married |
| o divórcio | divorce |
| o testamento | will / testament |
| os herdeiros | heirs / inheritors |
| a herança | inheritance |
| cá | here |
| lá | there |
| esta, essa, aquela | this, that, that over there (feminine) |
| este, esse, aquele | this, that, that over there (masculine) |
| tão | as / so (tão + adjective/adverb + como) |
| tanto | as much / so much (tanto/a/os/as + noun + como) |
| como | as / like / how |
| Comer legumes é tão bom para a saúde como comer fruta | Eating vegetables is as good for your health as eating fruit |
| As aulas de kizomba são tão divertidas como as aulas de samba | Kizomba classes are as fun as samba classes |
| Andar de metro é tão barato como andar de autocarro | Taking the metro is as cheap as taking the bus |
| Nós não temos tantos livros como vocês | We don't have as many books as you |
| A Teresa não tem tanto tempo livre como eu | Teresa does not have as much free time as me |
| tempo livre | free time |
| Praticar futebol tem tantas vantagens como praticar andebol | Playing football has as many advantages as playing handball |
| presenciais | in-person / face-to-face (plural) |
| eu vou em pessoa | I go in person |
| vou ter uma reunião online | I am going to have an online meeting |
| vou ter uma reunião presencial | I am going to have an in-person meeting |
